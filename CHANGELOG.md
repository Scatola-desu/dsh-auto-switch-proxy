# Changelog

## 1.0.1 — 2026-10-25

- Add a sidebar menu screenshot to the README.
- Merge the English and Chinese documentation into one `README.md` with side-by-side tables; `README.zh.md` is removed.

## 1.0.0 — 2026-10-25

- Initial public release.
- System, Direct, and rule-based Auto Switch modes.
- Separate server list with bare-port normalization.
- Manual rules and subscriptions in SwitchyOmega `.sorl` and AutoProxy formats.
- Periodic subscription updates with on-disk cache and a `ghproxy.net` fallback.
- Sidebar route menu and manager modal.
- Safe teardown: a direct dispatcher is installed before the Auto router stops.
